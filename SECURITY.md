# Security Policy

## Versiones Compatibles

Brasic se encuentra actualmente en su primera versión oficial, la V1.0. Las actualizaciones de seguridad se centrarán en la versión compatible que se indica a continuación.

| Version | Supported          |
| ------- | ------------------ |
|   1.0   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportando una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en Brasic, por favor infórmala de manera responsable.

Al reportar una vulnerabilidad, incluye la siguiente información siempre que sea posible:

Una descripción clara de la vulnerabilidad.
Pasos para reproducir el problema.
El impacto potencial de la vulnerabilidad.
Cualquier fragmento de código o mensaje de error relevante.

Por favor, evita divulgar públicamente las vulnerabilidades de seguridad hasta que hayan sido revisadas.

Puedes reportar vulnerabilidades abriendo una incidencia (*issue*) en el repositorio de GitHub de Brasic. Si se habilita un método de reporte privado, este debería ser la opción preferida para problemas de seguridad sensibles.

Los reportes se revisarán lo antes posible. Una vez evaluado el reporte, recibirás una actualización indicando si la vulnerabilidad ha sido aceptada para su investigación o rechazada, junto con cualquier información relevante.

Gracias por ayudar a mantener Brasic seguro y fiable.
